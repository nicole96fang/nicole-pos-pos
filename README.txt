GOH YEAN HUAN POS

Files:
- index.html: complete single-file POS app
- NeedMoodNiuNiu.ttf: custom font (if included)

How to upload:
1. Extract this ZIP.
2. Upload all files inside the extracted folder to the ROOT of your GitHub repository.
3. Keep index.html and NeedMoodNiuNiu.ttf side by side.
4. Commit the upload. If Vercel is connected to this repository, it should deploy automatically.

Features:
- Dashboard with today's sales, expenses, net profit and order count
- 7-day Profit Trend chart
- New Sale with quick menu, custom items and payment method
- Expense records with date, merchant and amount
- Transaction history, date filters, CSV export
- Reports and print view
- Editable menu
- Local browser save and JSON backup/restore

Important:
Data is saved in the browser on the device where it is entered. Export a backup regularly.
